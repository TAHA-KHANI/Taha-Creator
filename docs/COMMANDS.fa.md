# مرجع دستورها و دکمه‌ها

این فهرست از شرط‌های متنی سورس اصلی استخراج و با توضیح کاربرد تکمیل شده است. دکمه‌ها عموماً فقط در منوی مربوط کار می‌کنند؛ فرستادن نام هر دکمه از هر صفحه الزاماً کاری انجام نمی‌دهد. شمارهٔ خط به سورس اولیه مربوط است، نه فایل بازسازی‌شده. وجود مسیر در کد به‌معنی آزمون عملی تمام حالت‌هایش نیست.

سه سطح را اشتباه نگیر: مدیریت مرکزی برای خودت؛ ربات اصلی برای ساخت/مدیریت ربات؛ پنل فرزند برای طراحی دکمه‌های همان ربات.

| `/id` | هر سه | شناسهٔ عددی در خصوصی |

| `/mycoin` | اصلی | موجودی سکهٔ مرکزی |

| `/start GETFILE<کد>` | فرزند | دریافت فایل ثبت‌شده |

## دکمه‌های شیشه‌ای فروشگاه

کدهای `taiid-+-...` و `rad-+-...` به تأیید/رد آگهی مربوط‌اند و فقط مدیر بررسی مجاز است. `like-+-...` و `dislike-+-...` رأی آگهی، `mahsol-+-...` نمایش محصول، و `buy-...` خرید ربات با سکه است. این‌ها callback داخلی‌اند؛ به‌صورت پیام عادی ارسال نمی‌شوند. نسخهٔ جدید قیمت و مالک آگهی را در دیتابیس کنترل می‌کند و متن callback به‌تنهایی مرجع قیمت نیست.

## متغیرهای متن در ربات فرزند

این نام‌ها در متن محتوا جایگزین می‌شوند؛ دستورات BotFather نیستند. جایگذاری‌های قدیمی ساده و حساس به متن هستند. ابتدا یک متن آزمایشی کوتاه بساز.

| گروه | متغیرها |
|---|---|
| هویت کاربر | FIRSTNAME، LASTNAME، USERNAME، USERID، CHATID، BIO، PHONE |
| ربات و گروه | IDBOT، BOTUSER، BOTNAME، GPNAME، GPUSER، DESCRIOPTION، BOTMEM |
| پیام و دعوت | TEXT، MESSAGEID، COIN، MEMBER، LINK، ALLMEM، GETDICE، DICE، CHANCE |
| زمان میلادی | HOUR، MINUTE، SECOND، TIME، YEAR، MONTH، DAY، DATEM |
| زمان شمسی | DATESH، FASL، HAFTEH، BASTANIBORG، HEYVANSAAL، MAHFA، SALFA، ROOZFA |
| زمان ثبت | JOINDATEM، JOINDATESH، JOINTIME |
| فایل‌ها | PHOTO_ID، VIDEO_ID، VIDEO_NOTE_ID، STICKER_ID، DOCUMENT_ID، AUDIO_ID، VOICE_ID |
| عضو/مخاطب/نقشه | NEW_MEMBER_NAME، NEW_MEMBER_USERNAME، NEW_MEMBER_ID، CONTACT_NUMBER، CONTACT_NAME، CONTACT_ID، LONG_LOCATION، LAT_LOCATION |

متغیرهای قدیمی `PING`، `PROFILE_PHOTO` و `BOTLIST` در متن جایگزین‌ها دیده می‌شوند، ولی مقداردهی آن‌ها در همهٔ مسیرها کامل نیست؛ خروجی خالی ممکن است. متغیرهای نتیجهٔ فوتبال/بسکتبال/بولینگ نیز به پیام انیمیشن و مقدار ذخیره‌شده وابسته‌اند.

## توابع متنی پیشرفته

| خانواده | کاربرد |
|---|---|
| GETDATA | دریافت پاسخ URL عمومی؛ مسیر فیلد JSON نیز در کد پشتیبانی شده |
| GETDB / SETDB | خواندن/نوشتن متغیرهای تعریف‌شدهٔ ربات |
| STRLEN / STRLOWER / STRUPPER / STRREV | تبدیل یا اندازه‌گیری رشته؛ بعضی عملیات قدیمی بایت‌محورند |
| REPLACE / RANDOM | جایگزینی متن و تولید مقدار تصادفی در قالب قدیمی |
| SENDPHOTO / SENDVIDEO / SENDAUDIO / SENDVOICE / SENDSTICKER / SENDDOCUMENT / SENDVINOTE | ارسال رسانه از درون متن الگو |
| SENDCONTACT / SENDCHAT / SENDEMOJI | عملیات کمکی ارسال مخاطب/پیام/انیمیشن |
| POSTDEL / DELETE / EDITMSG | عملیات ویرایش/حذف پیام و حذف تأخیری وابسته به مسیر |
| ADD | تغییر امتیاز؛ ورودی عددی ساده استفاده شود، موتور محاسبهٔ عمومی نیست |
| SHARE / LIKE | دکمهٔ اشتراک‌گذاری و شمارندهٔ واکنش Inline |

این خانواده‌ها بخشی از زبان الگوی اختصاصی سورس‌اند، نه PHP استاندارد. نحوهای ترکیبی و همهٔ حالت‌های آن‌ها آزموده نشده‌اند؛ برای استفادهٔ روزمره گزینه‌های منویی مناسب‌ترند. در نسخهٔ بازسازی‌شده خروجی PHP روی سرور ربات اجرا نمی‌شود.
