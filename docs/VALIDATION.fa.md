# گزارش آزمون نسخهٔ 6.0-railway

تاریخ بررسی: ۲۰۲۶-۰۹-۲۲. آزمون‌ها با توکن ساختگی و جایگزین محلی ارتباط تلگرام اجرا شدند؛ هیچ پیام واقعی ارسال نشد.

| آزمون | نتیجه و دامنه |
|---|---|
| PHP 8.3 | بررسی نحوی ۱۴ فایل PHP موفق |
| tests/unit.php | موفق؛ رمز مجزای webhook، مسیر فرزند، رد شناسهٔ SQL نامعتبر، ماسک توکن، حذف ردیف خالی کیبورد، نوشتن اتمیک و جلوگیری از نوشتن بیرون DATA_DIR |
| tests/integration.php | موفق با MariaDB 10.11 محلی؛ schema، ساخت ربات، کسر دقیق ۵۰۰ سکه، رد ثبت تکراری بدون کسر دوباره، ذخیرهٔ متن فارسی و کوتیشن، حذف آپدیت تکراری، رد مدیر غیرمجاز و حذف/بازپرداخت |
| موتور قدیمی فرزند | اجرای /start، /panel، انتخاب محل و نوع دکمه، ثبت نام، ورود به ویرایش و ثبت مطلب موفق |
| دریافت محتوای دکمه | کاربر آزمایشی دوم دکمه را انتخاب کرد و درخواست sendMessage با همان متن ثبت‌شده تولید شد |
| دسترسی پنل فرزند | کاربر غیرمالک با /panel وارد پنل نشد |
| ربات‌ساز | /start منوی اصلی را تولید کرد |

این آزمون‌ها دو اشکال اجرایی دیگر را مشخص کردند: فراخوانی بدون ورودی getEditer در /panel و escape دوبارهٔ JSON هنگام ذخیرهٔ محتوا. هر دو اصلاح و مسیر مربوط دوباره اجرا شد.

## آنچه اینجا آزموده نشده

- ساخت نهایی تصویر Docker و اجرای Apache داخل آن؛ ابزار Docker در این محیط اجرا نشد.
- اجرای workflow روی GitHub و MySQL 8.4 واقعی؛ فایل workflow برای این آزمون آماده است، اما نتیجهٔ سبز آن هنوز گزارش نشده است.
- اتصال واقعی Railway، ثبت webhook با توکن واقعی، تحویل واقعی رسانه و پیام، پایداری Volume بعد از Redeploy و بازیابی بکاپ.
- همهٔ ۳۷۳ عنوان منو/فرمان، تمام ترکیب‌های فرم و قفل، خرید و انتقال، گروه، Inline، سرویس PHP بیرونی، RSS و بار چندکاربره.

بنابراین نسخه برای راه‌اندازی آزمایشی آماده شده، اما تأیید نهایی استفادهٔ عمومی نیازمند مراحل پذیرش README و AUDIT است. این گزارش گواهی امنیت یا تضمین بی‌نقصی نیست.

## اجرای مجدد آزمون‌ها برای توسعه‌دهنده

`php tests/unit.php` بدون دیتابیس اجرا می‌شود. آزمون integration به دیتابیس آزمایشی جدا، متغیرهای MYSQL، OWNER_ID، APP_SECRET، BASE_URL، DATA_DIR و `TC_TEST_DATABASE=true` نیاز دارد. آن را روی دیتابیس کاربران واقعی اجرا نکن، چون دادهٔ تست ایجاد و تغییر می‌دهد. GitHub Actions این متغیرها و دیتابیس جدا را فراهم می‌کند.

`tests/legacy_case.php` ابزار بازپخش یک پیام مصنوعی است. ابتدا با ورودی `setup` قالب تست را می‌سازد. سپس با ورودی‌های نام مسیر، متن پیام و شناسهٔ کاربر اجرا می‌شود؛ خروجی JSON درخواست‌های تولیدشده است. این ابزار به‌تنهایی assertion همهٔ قابلیت‌ها نیست.
